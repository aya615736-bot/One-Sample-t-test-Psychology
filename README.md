# One Sample T-test Analysis of memory scores
## Overview 
This project evaluates whether the mean memory retention scores of a sample differs significantly from a hypothesized population baseline standard PSPP (An open source alternative to IBM SPSS)
Note: This Analysis was conduced using a synthetic dataset created specifically for statistical practice and methodology demonestration*
## Data Description
-**Data Source:**Synthetic/Demo  Dataset( created for SPSS/PSPP methodology practice purposes)
-**Sample Size (N):15 Participants
-** Variable:**
-'Participant-ID': Participant identifier (Nominal)
-'Memory-score' : Continuous scale score (Interval/Ratio)
## Key Findings ( One-sample T-test analysis )
-**Test value (Hypothesized population mean ):**$/20$
-**Statistical Test result:**A One sample T-test revealed that the average memory score was significantly higher than the baseline value of 20, $t(140= 13.92) P<.001$
##Software Used
-PSPP ( IBM SPSS Syntax compatible )
## Result(APA Style)
>A one sample t-test was conducted to determine whether the average memory score of participants differed significantly from a baseline score of 20 the results indicated that the mean memory score ($M=36.27, SD=4.53$ ) was significantly higher than the baseline value of 20, $t(14)=13.92,P<.001$ (Two tailed ). The mean difference was $16.27$ with a 95% confidence interval ranging from $ 13.76$ to $18.77$
